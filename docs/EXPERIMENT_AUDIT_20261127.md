# 实验审计与补充结果

更新日期：2026-11-27

本文件记录独立审计结果。先前 README 和技术报告中的部分边界声明已据此修正。

## 1. 已修正的物理公式

### Diffusion-sorption

PDEBench 官方样本的 HDF5 `config` 属性包含全部 Freundlich 参数：

```text
D = 5e-4, por = 0.29, rho_s = 2880
k_f = 3.5e-4, n_f = 0.874, t_final = 500
```

官方有限体积方程对应：

```text
R(c) c_t = D c_xx
R(c) = 1 + (1-por)/por * rho_s * k_f * n_f * c^(n_f-1)
```

因而“官方数据缺少反应参数”的旧说法不成立。当前已加入正确的 interior residual
和浓度下限保护。

### 2D diffusion-reaction

旧实现误用了经典 Gray-Scott feed/kill 反应项。PDEBench 官方方程是：

```text
u_t = Du lap(u) + u - u^3 - k - v
v_t = Dv lap(v) + u - v
Du = 1e-3, Dv = 5e-3, k = 5e-3
```

该残差已修正。

### Incompressible NS

官方数据没有压力场，但可通过消去压力梯度，检查动量方程的散度缺陷：

```text
div(u_t + u grad(u) - nu lap(u) - particles * force) = 0
```

该指标已实现，并使用源文件中的 `particles` 与 `force`。

## 2. Burgers 与 Advection 残差可信度

官方 test split、三 seed。Burgers 的总体 residual 仍低于 PINO，但主要优势来自
时间边界；内部区和四阶差分不占优。

| Burgers residual | PG | PINO | 观测数据 |
|---|---:|---:|---:|
| overall | **0.244643** | 0.253297 | 0.213228 |
| boundary | **0.634041** | 0.702292 | 0.492399 |
| interior | 0.227397 | **0.221918** | 0.167455 |
| fourth-order | 1.372452 | **1.367258** | 1.375831 |

结论：不能把 Burgers 的总体 residual 优势写成“内部物理一致性全面胜出”。

Advection β=1 的优势在边界、内部和四阶差分上都保持：

| Advection residual | PG | PINO | 观测数据 |
|---|---:|---:|---:|
| overall | **0.102403** | 0.104623 | 0.125433 |
| boundary | **0.484084** | 0.487582 | 0.495957 |
| interior | **0.086763** | 0.089040 | 0.112449 |
| fourth-order | **1.412762** | 1.412843 | 1.410864 |

## 3. 统计检验

使用 Seed 7 的 1000 个 common test 样本，对每个样本做配对比较，并执行
20,000 次 paired bootstrap。四个主结论做 Holm 多重比较校正：

| 指标 | 平均差 PG - PINO | 95% CI | Holm p |
|---|---:|---:|---:|
| Burgers L2 | -0.001108 | [-0.001771, -0.000430] | **0.00126** |
| Burgers residual | -0.016260 | [-0.021050, -0.011237] | **5.85e-10** |
| Advection L2 | -0.000759 | [-0.001008, -0.000492] | **1.24e-08** |
| Advection residual | -0.002500 | [-0.003302, -0.001671] | **7.70e-09** |

负值表示 PG 更低。样本级配对检验支持总体指标差异，但不改变 Burgers
interior/high-order 的反例。

## 4. 外部泛化

### Burgers 未见粘度

使用官方 Burgers `Nu=0.1` test 集，模型仅训练于 `Nu=0.01`，不调参：

| 模型 | Test L2 | PDE residual |
|---|---:|---:|
| PG derivative refiner | 0.389759 | 0.966050 |
| FNO | 0.393204 | **0.957043** |
| 观测数据 residual | - | 0.749572 |

结论：当前 Burgers 模型不能零样本泛化到另一粘度，不能外报“多粘度通用”。

随后加入 192 参数粘度条件向量，并用 `Nu=0.01` train 8000 样本与 `Nu=0.1`
train 2000 样本联合微调。dev 只用两个粘度的 dev 集选模：

| 模型 | Nu=0.01 test L2 | Nu=0.1 test L2 |
|---|---:|---:|
| 原 `Nu=0.01` 模型零样本 | **0.0197** | 0.3898 |
| 条件化联合微调 | 0.0264 | **0.0388** |
| 条件化 + 0.2 distillation | 0.0262 | 0.0474 |

结论：粘度条件能显著恢复未见粘度精度，但当前联合模型仍牺牲一部分原粘度
最佳精度，不是无损多粘度替代。

### Advection 未见 β

β=1 学到的输出修正器零样本迁移到其他官方 β，不重新训练：

| beta | 修正后 L2 | 同 β FNO | 修正后 residual | 解析平移 residual | 结论 |
|---:|---:|---:|---:|---:|---|
| 0.1 | 0.001717 | 0.003802 | 0.052160 | 0.051496 | L2 胜 FNO，residual 与基线持平 |
| 0.2 | 0.002081 | 0.005010 | **0.048590** | 0.050125 | 双指标改善 |
| 0.4 | 0.002820 | 0.006037 | **0.054129** | 0.057832 | 双指标改善 |
| 0.7 | 0.004552 | 0.006435 | **0.074009** | 0.088092 | 双指标改善 |
| 1.0 | 0.005777 | 0.006626 | **0.102335** | 0.126372 | 双指标改善 |
| 2.0 | 0.009584 | **0.006389** | 0.236036 | 0.256029 | 应使用专用残差分支 |
| 4.0 | 0.018042 | **0.007262** | 0.541866 | 0.547983 | 应使用专用残差分支 |
| 7.0 | 0.033179 | **0.009003** | 0.848412 | 0.850612 | 仍失败 |

结论：β≤0.7 可零样本使用 β=1 输出修正器；β≥2 不应启用该零样本分支。

## 5. Diffusion-sorption 残差

当前 PG checkpoint 的 Test L2 为 `0.003330`，但 Freundlich residual RMS 为
`0.999855`；官方观测数据自身为 `0.531420`。局部输出分支在提高物理权重后能把
residual 压低，但 dev L2 从 `0.003305` 恶化到超过 `0.02`，不能作为候选。

结论：参数和公式已补，PG 的 diffusion-sorption 物理残差仍未通过。需要从
方程结构或时间积分层修正，而不是继续局部调权重。

## 6. 二维物理残差

### Diffusion-reaction

修正方程后的 relative residual：

| 模型 | Relative residual |
|---|---:|
| 观测数据 | **0.009507** |
| PG | 0.034724 |
| FNO | 0.136032 |

PG 明显优于 FNO，但仍不是 PDE residual 达到观测底噪的水平。

### Incompressible NS

压力消去后的动量散度缺陷：

| 模型 | Relative momentum divergence |
|---|---:|
| 观测数据 | 1.305054 |
| PG | 1.136847 |
| FNO | **1.095111** |

观测数据自身并未接近零，说明当前 `64 x 64` 降采样、交错网格近似和有限差分
不足以把该指标解释成绝对物理误差。因此只作为诊断，不作为 PG 胜出声明。

## 7. 当前可声明与不可声明

可声明：

- Advection β=1 的总体、内部、边界和四阶 residual 均优于 PINO。
- Burgers 的官方总体 residual 和 Test L2 低于 PINO，但 interior 和四阶 residual
  仍落后 PINO。
- 样本级配对统计在 Holm 校正后支持四个总体差异。
- 二维 diffusion-reaction 的修正物理残差明显低于参数匹配 FNO。

不可声明：

- Burgers 在内部区或高阶残差上全面优于 PINO。
- Burgers 已实现跨粘度泛化。
- Advection 的 β=1 修正器可直接用于 β≥2。
- Diffusion-sorption 已达到优于观测底噪的物理残差。
- NS 动量散度指标已经提供绝对意义上的物理正确性证明。
